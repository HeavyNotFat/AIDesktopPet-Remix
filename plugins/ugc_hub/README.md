# UGC 素材站

浏览、上传、下载社区分享的 Live2D / 静态形象素材。**全部操作都在设置页里点**，
不往右键菜单塞东西；联网与解包都在后台进程里跑，不会卡住桌宠（宿主 hook 默认只有 3 秒）。

素材站地址默认已经填好：`https://adp.cqjszx.cn`。

## 在哪操作

**设置 →「插件」→ UGC 素材站** —— 导航栏里只有这一条，页内用分区（`section` 栅格）+ 状态映射
（`map`）排版，从上到下：

| 分区 | 列数 | 内容 |
|:--|:--|:--|
| **状态** | 映射 | 素材站 / 账号 / 本次任务 / 素材列表 / 上传结果 / 安装目录 / 前几条预览 |
| **素材站** | 2 | `素材站地址`（整行）+ **测试连接**、**刷新素材列表**、**查看当前进度**、**退出登录** |
| **账号** | 2 | `用户名`、`密码` + **登录**、**注册新账号**、**清空密码框**（空服务器第一个注册的账号是管理员） |
| **查找素材** | 3 | `关键词`（跨 2 列）、`类型`、`每页条数`、`排序`、**搜索 / 刷新** |
| **下载** | 2 | `选择素材`（下拉框，列表里每条都在里面）、`安装目录`、`安装后的名字`、`覆盖同名目录`、`线程数`、`超时`、`校验 SHA-256`、`下载后解包`、`保留压缩包`、`完成时提示`、**下载选中并安装** |
| **上传** | 2 | `文件完整路径`、`显示名`、`类型`、`授权`、`标签`、`说明` + **开始上传** |
| **维护** | 3 | **清空本地列表缓存**、**清空任务状态**、**查看安装目录** + node 版本一行小字 |

上手四步：地址已经填好 → 账号分区登录（空服务器先「注册新账号」）→ 素材站分区点「刷新素材列表」
→ 下载分区挑一个点「下载选中并安装」。

## 后台任务怎么反馈

任务（列表 / 登录 / 上传 / 下载）都在独立的 node 子进程里跑，进度写在
`plugins/.data/ugc_hub-task.json`：

* 点任意按钮、或改任意设置项都会**重建这一页**，状态映射、素材列表、下拉框、上传结果都会跟着更新；
* 任务跑完时插件会在下一次交互（点桌宠、聊天结束）**自动弹一条提示**并刷新页面
  （可在下载分区关掉「完成时提示」）；
* 页面不会自己轮询，想让进度动起来就点一下「查看当前进度」。

## 一些行为

* 下载走 HTTP Range 多线程分片（默认 4 线程）；下完对一遍整包 sha256（可关），
  按需解包到安装目录下的同名文件夹，临时 zip 默认删掉（想留就打开「保留压缩包」）；
* 同一个文件重复上传不占两份空间（服务端按 sha256 去重，直接回已有条目）；
* 登录成功后插件只保存 token（`plugins/.data/ugc_hub.json`，已 gitignore）；
  `密码` 框里的内容由宿主明文写进 `resources/configure.json`，用完可以点「清空密码框」；
* 解包前会再查一遍条目路径（不许 `..`、绝对路径、反斜杠），服务端已经拦过一轮，这是兜底；
* 插件跑在 node 子进程里，能读写你的文件（这是插件本身的权限，不是沙箱）。

## 文件

| 文件 | 作用 |
|:--|:--|
| `main.js` | 插件入口：一页七个分区（section 栅格 + map 状态）+ 按钮派活 + 页面重建 |
| `ugc.js` | 纯逻辑：HTTP、多线程分片下载、三步分片上传、zip 解包（不依赖宿主，可单独测） |
| `ugc-worker.js` | 后台任务进程：list / me / ping / login / register / logout / download / upload |
