# 养成系统（移植版）

从 `.PluginDevOld/cultivation_system`（PyQt5 + qfluentwidgets 时代）搬过来的，现在是
本仓库插件系统里的一个 Python 插件，界面换成当前主题（hacker）的控件。

## 玩法

1. **点一下桌宠** → 金币 +1~5、好感 +1~3（设置里可以改金币上限）；
2. **商店**买吃的（金币不够会提示差多少）；
3. **背包**里点一下吃掉 → 饥饿 +N、好感 +N、经验 +N（吃饱了会拒绝）；
4. **AI 回答**也会给奖励：经验 +字数/40、好感 +字数/20；
5. **饥饿值随时间下降**（每 60~165 秒 -1），饿到 0 会喊饿；
6. 升级时**饥饿上限 +50**、当前饥饿 +40、好感 +50~100。

## 怎么用

* 右键桌宠 →「养成系统：打开面板」/「养成系统：状态」；
* 聊天里：`/养成`（打开面板）、`/状态`、`/买 可乐`、`/喂食 汉堡`；
* 面板上的三个按钮：点一下赚金币 / 刷新 / 关闭。

## 接了哪些 hook

| hook | 干了什么 |
| --- | --- |
| `on_load` | 读存档、注册菜单与命令、在 UI 线程起饥饿定时器 |
| `on_unload` | 停定时器、关窗口 |
| `on_command` | 菜单项与 `/命令` |
| `on_chat_reply` | 按回答长度给经验/好感 |
| `on_event` | `pet_click`（宿主在桌宠鼠标释放时发的）给金币 |
| `on_system_prompt` | 饿了/好感高时给模型加一句心情提示 |

## 与老版本的差异

* 界面换成本仓库主题的控件，窗口是独立的一扇（老版本塞在设置页里）；
* 存档从 `resources/config.json` 挪到插件存储（`plugins/.data/cultivation_system.json`）；
* 初始饥饿给 60/100（老版本一上来是满的，得等一分多钟才能喂第一口）；
* 聊天奖励改成按**回答字数**折算（老版本数的是流式片段数，跟模型分片方式绑定）；
* 加了设置项：点一下的金币上限、饿了是否提醒 AI。

数值公式（升级、掉级、好感升级、吃饱判定）沿用原来的写法，见 `cultivation_model.py`。

## 开发

```bash
python -m pytest tests/test_cultivation.py -q     # 数值逻辑（不依赖 Qt）
```

`cultivation_model.py` 是纯逻辑（`PetState`），`cultivation_window.py` 只负责显示与转发点击，
`main.py` 只做 hook 装配 —— 想改数值就只动第一个文件。
