# 桌宠扭蛋机

花金币抽收藏品的小玩法：五档稀有度、双保底、重复转星辉、每日签到，抽完还能让桌宠点评你的手气。

## 玩法

| 操作           | 说明                        |
|:-------------|:--------------------------|
| `/抽卡`        | 单抽，10 金币                  |
| `/十连`        | 十连，90 金币（省 10 金币）         |
| `/签到`        | 每天一次，白给 30 金币             |
| `/图鉴`        | 看收集进度（按稀有度分组）             |
| `/扭蛋`        | 打开扭蛋机面板                   |
| 右键桌面桌宠 → 扭蛋机 | 打开面板 / 直接来一发 / 看图鉴        |
| 摸桌宠          | 8% 概率抖出一枚金币（+5），抽卡货币的免费来源 |

## 概率与保底

| 稀有度 |   概率 | 重复转星辉 |
|:----|-----:|------:|
| UR  | 0.5% |   120 |
| SSR | 2.5% |    25 |
| SR  |  12% |     6 |
| R   |  30% |     2 |
| N   |  55% |     1 |

* **第 10 抽**必出 SR 以上；**第 80 抽**必出 SSR 以上（出高稀有度会重置对应计数）。
* 攒够 **60 星辉**可以直接换一个 UR（面板上的「星辉换 UR」）。

## 与 AI 的联动

* 「让桌宠点评」会把这次的抽取结果塞进聊天，让模型用自己的人设吐槽你的手气；
* 插件会往系统提示词里写一段扭蛋机说明（概率、保底、你当前的收集进度），
  所以你也可以直接在聊天里问"我这台扭蛋机爆率多少"。

## 实现

| 文件                     | 作用                                        |
|:-----------------------|:------------------------------------------|
| `plugin.json`          | 清单：id、入口、hook 与两项设置（初始金币、摸桌宠掉金币概率）        |
| `gacha_model.py`       | 纯逻辑：概率、保底、图鉴、星辉兑换（不依赖 Qt，可单测）             |
| `gacha_window.py`      | 面板：用 `stlibs.themes.hacker` 的控件拼的，配色按稀有度  |
| `main.py`              | hook 接线：菜单项、命令、面板按钮、`pet_click` 掉金币、系统提示词 |
| `resources/items.json` | 收藏品池（按稀有度分组），想加东西直接往里加                    |

状态（金币、星辉、保底计数、图鉴）都存在插件私有存储里（`plugins/.data/lucky_pet.json`），
停用插件再启用不会丢；`/签到` 的日期也记在里面，重启当天不能重复领。
